# Particle Clock with Backend Server

Анимация частиц, которая отображает время, текст и геометрические паттерны.

## Структура проекта

- `index.html` - фронтенд с анимацией частиц
- `server.py` - Python HTTP сервер для предоставления данных
- `data.json` - файл с данными для отображения

## Как запустить

### 1. Запуск backend сервера

```bash
python3 server.py
```

Сервер запустится на `http://localhost:8000`

### 2. Открытие фронтенда

Откройте `index.html` в браузере.

## Формат данных

`data.json` содержит массив объектов двух типов:

### Текстовые данные

```json
{
  "type": "text",
  "data": "HELLO"
}
```

Отображает текст из букв и цифр.

### Геометрические данные

```json
{
  "type": "geo",
  "data": [[10, 20], [30, 40], [50, 60]]
}
```

Отображает точки по указанным координатам (x, y).

## Как это работает

1. Анимация показывает текущее время
2. После цикла времени делается запрос к серверу
3. Если сервер отвечает - отображаются данные с сервера
4. Если сервер не отвечает - отображается случайный текст
5. Сервер возвращает объекты из `data.json` по кругу

## API

**Endpoint:** `GET http://localhost:8000/data`

**Ответ:**
```json
{
  "type": "text|geo",
  "data": "..."
}
```

## Настройка

Вы можете изменить порт сервера в `server.py`:
```python
PORT = 8000
```

И URL сервера в `index.html`:
```javascript
const SERVER_URL = 'http://localhost:8000/data';
```
